# Backstop (믿을구석)

혼자 일하는 사람의 사수. 지금은 견적부터 봐드립니다.

> **Backstop** — 야구에서 홈플레이트 뒤에 친 그물. 놓친 공이 관중석으로 날아가지 않게 막는다.
> 금융·계약에서는 '최후의 보증'을 뜻한다. 놓친 작업이 손해가 되기 전에 막는다는 뜻으로 골랐다.

외주 요청문을 넣으면 **거기 안 적힌 작업**까지 찾아내 공수와 계약 범위 문구를 만들어주는 도구.

- 원티드 AI Championship 2026 출품작 (과제 제출 마감 2026-09-20)

## 왜 만들었나

프리랜서가 외주에서 손해를 보는 원인은 **가격을 낮게 불러서가 아니라, 요청문에 안 적힌 작업을 견적에 못 넣어서**다.
그래서 이 도구는 견적 계산기가 아니라 **누락 탐지기**다.

**이 도구는 금액을 만들지 않는다.** 공수(시간)만 추정하고, 단가는 사용자가 입력한다.

## 실행

```bash
npm install
npm run dev          # http://localhost:3000
```

API 키가 없어도 동작한다 — 자동으로 예시(mock) 결과를 보여준다.
실제 분석을 하려면 `.env.local`에 키를 넣는다.

```bash
cp .env.example .env.local
# ANTHROPIC_API_KEY=sk-ant-...
```

## 구조

```
app/
  page.tsx                 입력 → 진행 → 결과 (한 페이지)
  api/extract/route.ts     Stage 1 — 적힌 것만 구조화 (추론 금지)
  api/analyze/route.ts     Stage 2 — 안 적힌 것 추론  ← 핵심
components/                결과 카드·판정 배너·진행 표시
lib/
  guard.ts                 입력 길이·호출 제한·킬스위치·mock 폴백
  anthropic.ts             API 호출 래퍼 (SDK 없이 fetch)
  estimate.ts              공수 × 일당 → 견적 (클라이언트 계산)
prompts/                   프롬프트 정본 (.md)
scripts/build-prompts.mjs  prompts/*.md → lib/prompts.generated.ts (prebuild 자동 실행)
golden/answers/golden.json 정답지 58개 — 채점 기준
golden/holdout.txt         점수 측정 전용 시험 문제 3건 (프롬프트에 인용 금지)
run.py  score.py           일괄 실행·채점 (프롬프트 개선용)
check_holdout.py           홀드아웃이 프롬프트에 새어들어갔는지 검사
```

프롬프트는 `prompts/*.md`가 정본이다. 서버리스 런타임에서 파일을 읽지 않도록 빌드 시점에 코드로 인라인한다.

## 2단 파이프라인

1. **Stage 1** — 요청문에 **글자로 적힌 것만** 구조화한다. 추론 금지. 항목마다 근거 원문 인용 필수
2. **Stage 2** — 아래 **8개 자리**를 순서대로 훑어 안 적힌 작업을 찾는다

| | 자리 | 대표 사례 |
|---|---|---|
| S1 | 한 줄로 적힌 큰 일 | "해외 결제(PG) 연동", "기존 계정이 그대로 로그인되어야" |
| S2 | "준비 중"이라고 적힌 것 | "준비 중: 추가 기능 정의" → 범위 상한 없음 |
| S3 | "우리가 직접 하겠다"는 것 | "QR 실물 제작은 저희가" → URL은 개발이 먼저 줘야 인쇄 시작 |
| S4 | 스스로 "아직 안 정했다"는 것 | 지역 확장 구조 = 아키텍처 결정 |
| S5 | 범위 밖으로 밀어둔 인접 시스템 | 웹뷰 브릿지의 웹 코드, 남겨둔 WordPress |
| S6 | 법적·행정 요건 | 약관, 위탁계약, 스토어 심사 규정, 폰트 라이선스, **지원 자격** |
| S7 | 기다리는 시간 (일한 시간 아님) | 50일 온콜, 격주 시연 8~9회, 매장 문의 대응, 종료 후 데이터 파기, 상주 근무 |
| S8 | 못 미루는 날짜 | 오픈일 고정 + 자료 지연, 착수일 미확정 + 완료일 고정, 계약 자동 연장 조항 |

S7·S8은 예시 목록 대신 **판단 질문**을 앞세운다. 처음 보는 형태도 질문 하나로 자리에 들어오게 하기 위해서다.

- S7 — "이 항목은 일한 시간인가, 묶여 있는 시간인가"
- S8 — "이 날짜가 밀리면 누가 손해를 보는가"

한 번에 다 시키면 "적힌 것"과 "추측한 것"이 섞여 어느 쪽이 틀렸는지 추적할 수 없다. 그래서 나눴다.

## 채점

```bash
python3 run.py     # 요청문 → stage1 → stage2 (ANTHROPIC_API_KEY 필요)
python3 score.py   # 정답지와 대조해 재현율 산출
```

- **high 재현율**이 주 지표다. 심각한 누락을 몇 % 잡아내는가
- 채점용 요청문 원문(`golden/requests/`)과 정답지 문서는 **타사 공고문이라 저장소에서 제외**했다

### 시험 문제 분리 (홀드아웃)

정답지가 있는 5건은 두 번 오염돼 **점수 측정에 쓸 수 없다** — ① 1차 실행에서 정답지 작성자와 실행자가 같았고, ② S7·S8을 보강하며 그 5건의 실제 문장을 프롬프트 예시로 넣었다. 답을 교과서에 적어놓고 그 시험을 보는 상태다.

그래서 점수는 `golden/holdout.txt`에 지정한 **별도 3건으로만 잰다.** 기존 5건은 프롬프트를 다듬는 연습용으로 쓴다.

```bash
python3 check_holdout.py          # 홀드아웃 문장이 프롬프트에 섞였는지 검사
python3 check_holdout.py 157981   # 특정 건만 임시 검사 (검사기 작동 확인용)
```

프롬프트를 고칠 때마다 돌린다. 오염이 있으면 종료 코드 1로 알린다.

## 비용·안전 가드

- 입력 6,000자 상한
- IP당 시간당 5회 제한 (인메모리, best-effort — 서버리스라 완벽하지 않음)
- `BACKSTOP_DISABLED=1` 킬스위치
- API 키는 서버 라우트에서만 읽는다. 클라이언트로 나가지 않는다
- **키가 없거나 킬스위치가 켜지면 자동으로 예시 모드** → 링크가 항상 무언가를 보여준다

## 로드맵

혼자 일하는 사람의 수주 사이클 중 지금은 ③만 구현했다.

① 노출 → ② 유입 진단 → **③ 견적·범위** → ④ 계약 → ⑤ 수행 → ⑥ 정산·회고

⑥의 실제 소요 데이터가 쌓이면 ③의 추정이 정확해진다. 그것이 이 서비스의 해자다.
